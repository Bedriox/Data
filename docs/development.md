# Development

## Requirements

- PHP 8.4 or later within the supported range.
- Composer 2.

```console
composer install
composer check
```

Do not add a third-party input, generated output, packet capture, or extracted game file until source, license, integrity, and redistribution review is complete. Generators must be deterministic, pinned, documented, and tested against small original fixtures.

Never make normal installation or startup silently download proprietary data. Update `CHANGELOG.md` for consumer-visible changes.
